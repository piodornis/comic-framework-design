## Exploration set

```markdown
# Style Exploration

Design state: EXPLORATION
Question being tested: ...

## Variant A
Changes: ...
What stays fixed: ...
Expected visual effect: ...

## Variant B
Changes: ...
What stays fixed: ...
Expected visual effect: ...

## Recommendation
Preferred direction: ...
Reason: ...
Creator decision required: yes
```

Do not label a preferred exploration `APPROVED` merely because it is recommended.
