## Location sheet plan

Use before generating a full location sheet.

```markdown
# Location Sheet Plan — <environment>

1. Exterior establishing view
2. Main interior establishing view
3. Reverse angle
4. Main entry / exit
5. Landmark close-up
6. Spatial diagram
7. Key props / machinery
8. Lighting state variant
```

Include only views that improve repeatability.

## Variant comparison

Use for bounded alternatives.

```markdown
| Criterion | Variant A | Variant B | Variant C |
| --- | --- | --- | --- |
| Spatial identity | ... | ... | ... |
| Style fit | ... | ... | ... |
| Story fit | ... | ... | ... |
| Repeatability | ... | ... | ... |
| Continuity risk | ... | ... | ... |
```

Do not select a winner unless the user asks for a recommendation. Do not mark it `APPROVED` without explicit creator approval.
