## Purpose

Use this protocol to develop environments that are visually distinctive, spatially usable, repeatable across panels, and compatible with story canon and project style.

## Design from function first

Before decorative detail, determine what the location or object must do.

For a location, ask:

- what narrative function does the place serve
- who uses it
- what activities happen there
- what entrances, exits, circulation, or access restrictions matter
- what scale relationships affect staging
- what must remain recognizable across repeated appearances

For a prop, machine, vehicle, or system, ask:

- what it does
- how people or characters interact with it
- how it is powered, moved, maintained, opened, stored, or repaired when story-relevant
- which details are essential for recognition

Do not add complexity only because a design feels visually empty.

## Translate narrative constraints carefully

Convert established story facts into visual requirements without silently creating new world facts.

Example:

```text
CANON: the district is resource-poor.
Visual implication: repaired surfaces, reused modules, visible maintenance, mixed-era infrastructure may be plausible.
Status: INFERENCE until the project confirms the exact visual consequences.
```

If a visual solution implies a new social rule, technology, resource, faction practice, or historical event, label that implication `PROPOSAL` or `CONFLICT` as appropriate.

## Separate mood from geometry

Treat these as different layers.

Mood may include:

- color
- weather
- haze
- light quality
- density
- cleanliness
- texture
- sound or implied atmosphere

Geometry includes:

- entrances and exits
- room adjacency
- levels
- landmark placement
- circulation
- sight lines
- scale

A location can be atmospherically consistent while spatially contradictory. Preserve both where the location recurs.

## Build spatial identity

Use a small number of strong anchors rather than many interchangeable details.

Good anchors include:

- a dominant machine
- a central void
- a distinctive stair or bridge
- a specific window rhythm
- an asymmetrical entry sequence
- a recurring sign system
- a skyline feature
- a unique floor or wall module

Anchors should help artists or image systems recognize the location from several angles.

## Use scale deliberately

Define relative scale with known references when useful:

- character height
- door height
- vehicle width
- floor-to-floor distance
- machine diameter

Avoid false precision when the story does not need measurements.

Use scale to support narrative effect: intimacy, oppression, openness, danger, bureaucracy, ritual, or isolation.

## Design architecture as a system

Prefer coherent rules over unrelated decoration.

Define patterns such as:

- structural rhythm
- repeated modules
- construction logic
- exposed versus concealed systems
- ornament density
- age layers
- maintenance culture
- interface language

If the environment belongs to a faction or institution, translate its values into visual choices only where supported by canon or clearly marked inference.

## Materials and wear

State primary and secondary materials and how they age.

Consider:

- clean versus repaired surfaces
- oxidation, scratches, dirt, fading, polish, or deformation
- local resource availability
- maintenance frequency
- replacement modules
- environmental exposure

Do not apply random wear uniformly. Wear should follow use, age, environment, and maintenance logic.

## Lighting and atmosphere

Define lighting as part of location identity when recurring.

Capture:

- source type
- direction
- contrast
- color temperature or palette relation
- volumetric effects
- day/night or operational states

Separate stable lighting identity from scene-specific dramatic lighting.

## Landmarks and orientation

Provide visual cues that help repeated staging.

Use:

- color-coded zones
- recurring signs
- major doors
- vertical shafts
- equipment clusters
- windows or exterior views
- architectural asymmetry

For complex locations, a simple diagram may be more useful than additional rendered images.

## Props machinery vehicles and signage

In v1, handle recurring world objects here when they are environmental rather than character-specific.

For each recurring object, define only what supports continuity:

- silhouette
- scale
- interaction points
- materials
- markings
- moving or functional parts
- orientation-sensitive features

Keep signage systems consistent in typography class, icon language, placement logic, and color behavior without inventing text that changes canon.

## Style Pack integration

Use the active Style Pack to govern visual treatment, including:

- linework
- simplification
- shape language
- color behavior
- material rendering
- shadow geometry
- detail density

Do not rewrite the Style Pack inside every environment record. Record only environment-specific application rules or exceptions.

## Transformation Profile integration

When starting from a photo or existing location image, let the Transformation Profile control source fidelity.

Typical preserved properties may include:

- camera composition
- architecture
- landmark placement
- object identity
- signage layout when relevant and permissible

The Style Pack then controls the visual treatment.

Do not confuse a faithful transformation of a photograph with a permanent project environment design. Promote repeated visual facts into the environment record only when accepted.

## Repeatability for comics

A strong environment design must be reproducible from multiple viewpoints.

Before considering a design mature, test whether another artist or generation can answer:

- what makes this location recognizable
- where characters enter or leave
- which landmarks must persist
- what the key materials are
- what the dominant scale is
- what may vary between scenes

If the answer depends on one exact camera angle, the environment is not yet robust enough for recurring use.

## Canon and design boundaries

Never use attractive visual detail to silently establish narrative truth.

Examples requiring story-side review:

- faction emblems not previously established
- weapons or security systems
- religious symbols
- historical damage
- class segregation cues
- transport rules
- new technologies
- environmental hazards

Keep the design exploration, but label the story implication clearly.

## Review checklist

Before presenting an environment direction, verify:

- function is clear
- scale is readable
- spatial identity survives more than one view
- active Style Pack is applied coherently
- existing approved or locked anchors were preserved
- references were used only for their intended roles
- recurring landmarks are concrete
- material and wear logic is coherent
- lighting is distinguishable from geometry
- props and machinery are repeatable
- story implications are labeled
- unresolved conflicts remain visible
- design state is not promoted without creator approval
